# SpecStory history

This directory holds **SpecStory** (or similar) exports of Cursor/VS Code AI prompts and sessions.

## Setup

1. Install the SpecStory extension for Cursor or VS Code.
2. Configure it to save history into this folder (or copy exports here after each session).
3. Index each session in [`docs/prompt-history.md`](../../docs/prompt-history.md) with date, goal, spec files touched, and outcome.

## Submission

The assignment expects prompt history in the repository. Commit meaningful session files here; avoid secrets or pasted credentials in chat exports.
